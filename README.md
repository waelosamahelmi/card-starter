# Card starter

A one-page personal card, built with [Vite](https://vite.dev). No framework, just
HTML, CSS and a few lines of JavaScript.

## Run it

You need Node.js 20.19 or newer (`node --version` to check).

```bash
npm install     # installs the exact versions in package-lock.json
npm run dev     # starts a local server at http://localhost:5173
```

## Build it

```bash
npm run build   # writes the finished site to dist/
npm run preview # serves dist/ locally, the way a host would
```

## Files

- `index.html` — the page itself. Start here.
- `style.css` — how it looks.
- `main.js` — loads the CSS and fills in the footer year.
- `package.json` — the project's name, its scripts, and its dependencies.
- `package-lock.json` — the exact version of every installed package. Commit it; never edit it by hand.
